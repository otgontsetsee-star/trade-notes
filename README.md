# Trade notes

Алт ба GBPJPY арилжааны хувийн журнал: P&L хуанли, дүрмийн автомат шалгалт, том мэдээний сэрэмжлүүлэг, MT5 тайлан импорт.

## Файлууд

| Файл | Юу вэ |
|---|---|
| `index.html` | Апп бүхэлдээ (нэг файл) |
| `events.json` | Эдийн засгийн том мэдээний хуваарь (2026-09 … 2026-12) |

## Хадгалалт

Арилжааны өгөгдөл энэ repo-д **байхгүй** — зөвхөн таны хөтөч (browser) дээр хадгалагдана.
Тохиргоо → **Нөөц татах** товчоор 7 хоног тутам нөөц файлаа хадгалж байгаарай.
Нөөц файлаа (`trade-notes-backup-….json`) энэ repo руу **бүү** оруулаарай — repo нийтэд нээлттэй.
